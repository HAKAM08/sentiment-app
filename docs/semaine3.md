# Semaine 3 — Interface de démonstration

Nous retenons un seuil d'incertitude de 0,60 afin de privilégier
un compromis entre automatisation et fiabilité des prédictions.

Sur le jeu de démonstration, l'interface envoie à un agent les avis
dont le score est inférieur au seuil retenu.

Ce compromis permet de traiter automatiquement les avis suffisamment
clairs tout en laissant un contrôle humain sur les cas incertains.
